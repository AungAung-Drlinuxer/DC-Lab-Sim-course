## E2. Drill 1 — Weak Area Quick Quiz ကိုယ်တိုင် ရေးခြင်း

ကိုယ့် အားနည်း domain (score <70% ရှိသော) မှ အကြောင်းအရာ ၁၅ ခု ရွေးပြီး
**15 မေးခွန်း Quick Quiz ကို ကိုယ်တိုင် ရေး**ပါ —

1. မေးခွန်း ၁၀ ခု = multiple choice (ရွေးချယ်စရာ ၄ ခု)
2. မေးခွန်း ၃ ခု = tool output ဖတ်ရှုခြင်း (output တစ်ခု ပေးပြီး ဘာ ပြောနေသလဲ မေး)
3. မေးခွန်း ၂ ခု = sequence ("next step" ပုံစံ)
4. မေးခွန်း တစ်ခုချင်းစီအတွက် အဖြေ + တစ်ကြောင်း အကြောင်းပြချက် ရေးပါ
5. ၁၅ မိနစ် timer ဖြင့် ကိုယ်တိုင် ရေးထားသော quiz ကို ပြန်ဖြေပါ (အဖြေ မကြည့်ဘဲ)

## E3. Drill 2 — Time Pacing Drill

Full Practice Exam အတွက် အချိန် စီမံခန့်ခွဲမှု ကို ကြိုတင် လေ့ကျင့်ပါ —

1. 60 မေးခွန်း (ယခင် ဖြေဖူးသော Full Practice မှ ပြန်သုံးနိုင်) ကို
   **90 မိနစ်** budget ဖြင့် ပြန်ဖြေပါ
2. မေးခွန်း ၁ ခုချင်းစီတွင် ကုန်သွားသော အချိန် မှတ်ပါ — **1.5 မိနစ်** ထက်
   ကျော်သော မေးခွန်း များ စာရင်း ပြုစုပါ
3. ၉၀ စက္ကန့် ကျော်သော မေးခွန်း တစ်ခုချင်းစီအတွက် — "ဘာကြောင့် ကြာသလဲ"
   (အကြောင်းအရာ မသိခြင်း vs ဖတ်ရှုမှု နှေးခြင်း vs ရွေးချယ်စရာ ရှုပ်ခြင်း) ခွဲခြားပါ
4. နောက် တစ်ကြိမ် ပြန်ဖြေရာတွင် ထို မေးခွန်း အမျိုးအစား အတွက်
   ကိုင်တွယ်ပုံ ပြင်ပါ (flag လုပ်ပြီး နောက်မှ ပြန်ခြင်း စသည်)

## E4. Drill 3 — Live Incidents Triage Speed Drill

Sandbox tab တွင် fault injection သုံးပြီး triage အမြန်နှုန်း လေ့ကျင့်ပါ —

1. Sandbox တွင် fault တစ်ခု inject ပါ (XID Error / ECC Error / Thermal Issue /
   NVLink Down ထဲမှ — "Surprise me" ဖြင့်လည်း ရပါသည်)
2. Timer စပြီး Explanation §4.2 အတိုင်း ၄ အဆင့် လုပ်ပါ —
   State → Logs → Fabric → Physical → validate
3. **diagnosis အချိန်** (fault အမျိုးအစား သိသည်အထိ) ကို သီးခြား မှတ်ပါ
4. ၃ ကြိမ် ပြန်လုပ်ပြီး diagnosis အချိန် တိုးတက်မှု ကို နှိုင်းယှဉ်ပါ
5. ပြီးမှ သာ Live Incidents အမှတ်ပေး စနစ်ထဲ ဝင်ပါ (unlock ဖြစ်ပြီး ဆိုပါက)

```
ဒုတိယ ကြိမ် diagnosis time: __:__   တိုးတက်မှု: ____
```
